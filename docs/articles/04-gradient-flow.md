# 从零开始学深度学习 #04：梯度消失与梯度爆炸

上一篇我们搭好了 PyTorch 的地基。这一篇回到主线，去拆深度网络训练里最要命的一个问题。

回忆《从零开始学机器学习》里手推过的反向传播：误差从输出层出发，沿网络一层层往回传，每传一层，梯度就乘以这一层的某个数。深层网络的问题，就出在"连乘"这两个字上。

## 一、梯度是一路乘回去的

反向传播的本质，是把最终误差对每一层参数的"影响程度"算出来。这个影响程度，是沿着网络从后往前，一路做乘法得到的。

```mermaid
---
title: 反向传播：误差逐层连乘回传
---
flowchart LR
    A[输出层误差] -->|乘 0.25| B[倒数第二层]
    B -->|再乘 0.25| C[倒数第三层]
    C -->|再乘 0.25| D[更前面的层]
```

每一层乘的那个数，等于"这层激活函数的导数 × 权重"。如果每层都乘一个小于 1 的数，乘上几十次，最前面几层的梯度就会小到几乎消失——这就是**梯度消失**。反过来，如果每层都乘一个大于 1 的数，几十次连乘下来，梯度会爆炸式膨胀——这就是**梯度爆炸**。

## 二、为什么 Sigmoid 特别容易消失

问题出在激活函数的导数上。Sigmoid 函数长这样：把任意输入压到 0 到 1 之间。它有个致命的性质——导数最大只有 0.25。

:::formula Sigmoid 的导数上限
sigmoid'(x) ≤ 0.25
sigmoid'：导数 ｜ 对任何输入 x，导数值都不超过四分之一
:::

这 0.25 就是那"每层乘的数"。一个 30 层的 Sigmoid 网络，梯度在最前面一层被连乘了 30 个 0.25：

:::formula 梯度消失的数学
0.25³⁰ ≈ 0.0000000000000000009
连乘 30 个 0.25，结果小到可以忽略不计
:::

更糟的是，Sigmoid 在输入很大或很小时，会进入"饱和区"——导数趋近于 0。真实训练里，激活值经常落在饱和区，于是那"每层乘的数"连 0.25 都不到，往往只有 0.01、0.001。

## 三、做个实验：Sigmoid 深层网络学不动

光推导不直观，跑一个真实网络看看。

我搭了两个 20 层的全连接网络，唯一的区别是激活函数：一个用 Sigmoid，一个用 ReLU。前向传播算一次、反向传播算一次，然后打印每一层权重的梯度范数——这个数代表"这一层到底学到了多少"。

![Sigmoid 与 ReLU 深层网络各层梯度对比](gradient_flow.png)

结果触目惊心。Sigmoid 网络里，越靠近输入端的层，梯度越小，最前面几层在图上几乎贴着 0——它们根本没在学。而 ReLU 网络里，每一层的梯度都保持在一个健康的大小。

这就是为什么当年人们发现"神经网络加深了反而更差"——不是深没用，是梯度在半路就消失了，前面的层形同虚设。

## 四、爆炸：另一个极端

消失的反面是爆炸。如果每层乘的数大于 1，比如权重初始化得太大，几十次连乘下来，梯度会大到离谱。表现就是损失值突然变成 NaN——数值溢出了，训练直接崩掉。

消失和爆炸，本质是同一个问题的两个方向：**深层网络里，信号在前向或反向传递时会失控地衰减或放大**。

## 五、解法藏在三个地方

好消息是，这个问题有救，而且救它的三样东西，就是接下来三篇的主角：

- **换激活函数**：ReLU 的导数恒为 1（正数区），不再有 0.25 的衰减。
- **好好初始化**：让每层"乘的那个数"一开始就接近 1，信号不衰减也不爆炸。
- **归一化**：在每层之间把信号"拉回"标准分布，从根上阻止它跑偏。
