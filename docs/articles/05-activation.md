# 从零开始学深度学习 #05：激活函数

上一篇留了个钩子：梯度消失的头号元凶，是 Sigmoid 的导数太小。解法之一，是换个激活函数。

这一篇就把这个"换"字讲透。激活函数到底是干嘛的、Sigmoid 为什么不行、ReLU 凭什么成了默认选择，最后看一眼它身后的整个家族。

## 一、激活函数：给网络装"非线性"

先回答最基础的问题：为什么要激活函数？

回忆第一篇搭过的网络：`nn.Linear` 层做的事，是加权求和。如果把很多个 Linear 层首尾相接，不加任何东西——那无论叠多少层，整个网络都还是一个线性变换，等价于一个 Linear。

```mermaid
---
title: 没有激活函数，叠多少层都是线性
---
flowchart LR
    A[线性层] --> B[线性层] --> C[线性层]
    C --> D[合并后仍是线性]
```

是激活函数把"非线性"塞了进来，让网络能表达弯曲的边界、复杂的映射。第一篇里那个能分开两条螺旋的深层网络，靠的就是一层层 `Tanh` 叠出来的非线性。

## 二、Sigmoid 的致命伤：饱和

Sigmoid 的历史很悠久，但它有两个毛病，在深层网络里是致命的。

第一个毛病上一篇已经讲过：导数最大只有 0.25，梯度连乘后消失。第二个毛病更隐蔽——**饱和**。

看 Sigmoid 的形状：输入超过 ±3 之后，输出几乎贴平在 0 和 1 上不动了。这个"贴平"的区域叫饱和区。一旦激活值掉进饱和区，导数趋近 0，反向传播时梯度就在这一层被"掐死"。

![各激活函数形状与导数对比](activations.png)

左图是各函数的形状，右图是导数。注意 Sigmoid 的导数（红虚线区）最高点也只有 0.25，两侧迅速跌向 0。

## 三、ReLU：一个 if 语句解决了问题

2012 年 AlexNet 用了 ReLU，效果立竿见影。它的定义简单到可以用一行代码写出来：

```python
def relu(x):
    return x if x > 0 else 0   # 正数原样过，负数归零
```

正数区，ReLU 的输出就是输入本身，导数是 1——没有衰减。负数区，输出归零，导数也是 0。

关键在于：ReLU 在正数区"不饱和"。信号再大，导数也稳稳是 1，梯度可以畅通无阻地穿过这一层。于是深层网络的梯度不再一路衰减，前面的层终于学得动东西了。

:::formula ReLU 的导数
relu'(x) = 1  (x > 0) ｜ 0  (x ≤ 0)
正数区导数恒为 1，梯度不再消失
:::

它也有代价：负数区导数恒为 0，那些"输出为负"的神经元就"死"了，永远不再更新。这个问题催生了后续的一堆改良。

## 四、ReLU 家族：一代代改良

ReLU 之后，人们沿着它的思路修修补补，发展出一整个家族：

- **Leaky ReLU**：负数区不再归零，而是给一个很小的斜率（比如 0.01），避免神经元"死掉"。
- **ELU**：负数区给一个光滑的负值，让输出均值更接近 0。
- **GELU**：现在 Transformer 里的标配。它不粗暴地"负数归零"，而是按高斯分布的概率"软性"地决定要不要过——更平滑，也更适合深层大模型。

这些改良各有取舍，但万变不离其宗：**在正数区保持导数接近 1，同时尽量减少负数区的"死神经元"**。

## 五、怎么选

实战里有个朴素的默认值：搭网络不知道用什么，先用 ReLU；如果发现很多神经元"死掉"了（大量输出恒为 0），换 Leaky ReLU；在 Transformer 这类现代架构里，直接用 GELU。

激活函数没有"最好"，只有"适合"。但有一点是确定的：别再默认用 Sigmoid 当隐藏层激活了——它在深层网络里的饱和问题，已经被 ReLU 家族取代。
