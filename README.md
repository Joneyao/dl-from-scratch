# dl-from-scratch

从零开始学深度学习 —— 用 PyTorch 亲手实现深度学习核心机制，配套《从零开始学深度学习》系列文章。

## 这个仓库是干什么的

不追求性能，也不追求覆盖所有模型，追求一件事：**把每个深度学习核心技术点的核心逻辑用最朴素的代码亲手写一遍**，让你看到的每一行都不是黑盒。每个机制先手写最小实现（卷积、池化、BatchNorm、Dropout、LSTM 门控、注意力……），再用 PyTorch 框架版做数值对照——你手写的原理，框架一行 API 就调用。

每个模块都自包含：核心实现 + 最小可跑示例 + 导出真实运行数据的绘图脚本（文章里的每张图都来自代码真实输出，不是画的）。

## 目录结构

```
dl-from-scratch/
├── common/           # 公共工具：绘图字体辅助、训练循环骨架
├── intro/            # 导论与工具（#01-03）：浅层 vs 深层、PyTorch 快速上手
├── training/         # 训练地基（#04-09）：梯度、激活、初始化、归一化、优化器、正则化
├── cnn/              # 卷积神经网络（#10-14）：卷积、池化、经典架构、ResNet、实战
├── rnn/              # 循环神经网络（#15-17）：RNN、LSTM、GRU 与序列生成
├── transformer/      # 注意力与 Transformer（#18-21）：注意力、自注意力、架构、BERT/GPT
├── summary/          # 收尾（#22）：全景图与学习路线
└── docs/
    ├── references.md # 官方教程 + 经典书籍 + 开源仓库清单
    └── articles/     # 配套系列文章 markdown（与公众号双发）
```

## 快速开始

```bash
pip install -r requirements.txt
python -m pytest -v                      # 跑全部测试
```

## 参考资料

代码根据官方教程、经典教材和开源教学仓库的原理从零重新实现，**只借鉴思路和边界处理，不摘抄任何开源项目源码**。参考清单见 [docs/references.md](docs/references.md)，主要包括：《动手学深度学习》(d2l)、《深度学习》花书、邱锡鹏《神经网络与深度学习》、斋藤康毅《深度学习入门》、PyTorch 官方教程，以及 d2l-ai/d2l-zh、karpathy/nn-zero-to-hero、labmlai 等（思路参考）。

## 开发约定

- **代码先行 + 真实数据配图：** 每个模块先实现、跑通、导出真实中间数据，这些数据直接作为配套文章的配图，可追溯到代码输出。
- **手写核心 + 框架对照：** 每个技术点先手写最小实现讲清原理，再用 PyTorch 框架版做数值对照验证正确性。
